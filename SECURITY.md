# Reporting a security vulnerability

Please do not publish vulnerabilities, tokens, credentials or personal financial data in public issues or PRs.

Use GitHub's **Security → Report a vulnerability** on this repository when private vulnerability reporting is enabled:

https://github.com/NDT2000/Finance-Tracker/security/advisories/new

If that option is unavailable, request a private contact channel from the maintainer without disclosing exploit details publicly. Do not include real user data in a report. Provide a synthetic reproduction, affected commit and potential impact through the private channel.

This document does not enable GitHub's private reporting setting; the maintainer setup guide describes that separate step.
